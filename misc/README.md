# Miscellaneous Templates

This directory contains templates for applications that don't fit into other categories.

## Example Applications

### Monitoring & Analytics
- Grafana - Metrics visualization
- Prometheus - Monitoring system
- Zabbix - Enterprise monitoring
- ELK Stack - Elasticsearch, Logstash, Kibana

### Development Tools
- GitLab - Git repository management
- Jenkins - Continuous Integration/Deployment
- SonarQube - Code quality analysis

### Media Servers
- Plex - Media server
- Jellyfin - Open-source media server
- Emby - Media server

### Proxy & VPN
- Squid - Caching proxy
- OpenVPN - VPN server
- WireGuard - Modern VPN

### Container & Orchestration
- Docker - Container runtime
- Kubernetes tools
- Portainer - Container management

## Template Requirements

Each miscellaneous template should include:
- Clear description of purpose
- Installation requirements
- Configuration steps
- Port and resource requirements
- Use cases and examples

## Adding Templates

If you're adding a template that doesn't fit existing categories:
1. Consider if a new category should be created
2. Document clearly what the application does
3. Include comprehensive setup instructions
