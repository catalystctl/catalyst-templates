# Voice Server Templates

This directory contains templates for voice communication servers.

## Supported Voice Servers

### TeamSpeak
- TeamSpeak 3 server
- Default port: 9987 (UDP)
- Query port: 10011 (TCP)
- File transfer: 30033 (TCP)

### Mumble
- Murmur server (Mumble server)
- Default port: 64738 (TCP/UDP)
- Low latency voice communication

### SinusBot
- TeamSpeak and Discord music bot
- Web interface for management

## Template Requirements

Each voice server template should include:
- Server version
- Port requirements
- User/channel limits
- Configuration files
- Permission system setup
- Admin credentials
- Codec settings

## Usage Notes

- Configure appropriate user slots based on your license/capacity
- Set up proper admin permissions
- Consider firewall rules for UDP traffic
- Regular backups of server databases and configurations
