# MOBA (Multiplayer Online Battle Arena) Game Templates

This directory contains templates for MOBA game servers and custom game modes.

## Popular MOBA Games

- **Dota 2** (custom games)
- **League of Legends** (custom servers/modes)
- **Heroes of the Storm**

## Template Guidelines

MOBA templates typically include:
- Custom game mode configurations
- Bot difficulty settings
- Match duration limits
- Team balance settings
- Map-specific configurations
