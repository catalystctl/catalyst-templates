# RTS (Real-Time Strategy) Game Templates

This directory contains templates for RTS game servers.

## Popular RTS Games

- **Age of Empires II**
- **Age of Empires III**
- **Age of Empires IV**
- **StarCraft II** (custom games)
- **Company of Heroes**

## Template Guidelines

RTS game templates should include:
- Lobby settings
- Game speed configurations
- Map pool settings
- Player limit configurations
- Replay storage
