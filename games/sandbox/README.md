# Sandbox Game Templates

This directory contains templates for sandbox and open-world game servers.

## Popular Sandbox Games

- **Minecraft** (Java Edition, Bedrock Edition, modded servers)
- **Terraria**
- **Garry's Mod**
- **Space Engineers**
- **Starbound**
- **Unturned**

## Template Guidelines

Each game template should include configuration for:
- World generation settings
- Player limits
- Mod/plugin support
- Backup schedules
- Performance optimization
