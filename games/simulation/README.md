# Simulation Game Templates

This directory contains templates for simulation game servers.

## Popular Simulation Games

- **Farming Simulator**
- **Euro Truck Simulator 2**
- **American Truck Simulator**
- **Microsoft Flight Simulator**
- **DCS World**

## Template Guidelines

Simulation game templates should include:
- Economy settings
- Traffic density
- Multiplayer sync settings
- Weather synchronization
- Time acceleration
- Mod/DLC requirements
