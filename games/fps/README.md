# FPS (First-Person Shooter) Game Templates

This directory contains templates for FPS game servers.

## Popular FPS Games

- **Counter-Strike: Global Offensive (CS:GO)**
- **Counter-Strike 2 (CS2)**
- **Team Fortress 2**
- **Insurgency: Sandstorm**
- **Squad**
- **Post Scriptum**
- **Hell Let Loose**
- **Pavlov VR**

## Template Guidelines

Each FPS game template should include:
- Game mode configurations
- Map rotation settings
- Server tick rate
- Anti-cheat settings
- Custom content/mods
- Admin tools configuration
