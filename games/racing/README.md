# Racing Game Templates

This directory contains templates for racing game servers.

## Popular Racing Games

- **Assetto Corsa**
- **Assetto Corsa Competizione**
- **iRacing**
- **rFactor 2**
- **Project Cars 2**
- **BeamNG.drive**

## Template Guidelines

Racing game templates should include:
- Track selection and rotation
- Race duration/laps
- Vehicle restrictions
- Weather and time settings
- Damage models
- Practice/qualifying/race session lengths
