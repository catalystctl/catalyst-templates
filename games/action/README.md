# Action Game Templates

This directory contains templates for action game servers.

## Popular Action Games

- **Grand Theft Auto V** (FiveM, RageMP)
- **GTFO**
- **Killing Floor 2**
- **Left 4 Dead 2**
- **Payday 2**

## Template Guidelines

Action game templates should include:
- Mission/scenario settings
- Difficulty configurations
- Enemy spawn settings
- Loot/reward configurations
- Cooperative play settings
