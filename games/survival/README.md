# Survival Game Templates

This directory contains templates for survival game servers.

## Popular Survival Games

- **Rust**
- **ARK: Survival Evolved**
- **7 Days to Die**
- **Valheim**
- **The Forest**
- **Conan Exiles**
- **DayZ**
- **Project Zomboid**

## Template Guidelines

Each survival game template should include:
- Server rates and multipliers
- PvP/PvE settings
- Resource gathering rates
- Taming/breeding configurations (if applicable)
- Difficulty settings
- Wipe schedules
