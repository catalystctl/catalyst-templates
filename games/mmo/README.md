# MMO (Massively Multiplayer Online) Game Templates

This directory contains templates for MMO game servers.

## Popular MMO Games

- **World of Warcraft** (private servers - WoW, TBC, WotLK)
- **Ragnarok Online**
- **MU Online**
- **Lineage II**
- **MapleStory** (private servers)

## Template Guidelines

MMO server templates are typically more complex and should include:
- Database server configuration
- Authentication server setup
- World server configuration
- Character server settings
- Client version compatibility
- GM (Game Master) tools
- Rate configurations (XP, drop, etc.)
